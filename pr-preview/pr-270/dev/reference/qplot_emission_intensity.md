# Create a quick emission intensity plot

Compared to
[`plot_emission_intensity()`](https://rmi-pacta.github.io/r2dii.plot/reference/plot_emission_intensity.html)
this function:

- is restricted to plotting future as 5 years from the start year,

- outputs formatted labels, based on emission metric column,

- outputs a title,

- outputs formatted axis labels.

## Usage

``` r
qplot_emission_intensity(data)
```

## Arguments

- data:

  A data frame like the output of
  [`prep_emission_intensity()`](https://rmi-pacta.github.io/pacta.loanbook/dev/reference/prep_emission_intensity.md).

## Value

An object of class "ggplot".
